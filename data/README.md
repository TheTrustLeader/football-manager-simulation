# data/

Real-world football data, used to date the engine's calibration bands.

Nothing in here is generated by the game. It is outside evidence, kept small and
checkable so that any figure in `engine-config.ts` can be traced back to matches
that were actually played.

## english-first-division-seasons.csv

One row per season of the English top flight (First Division to 1991/92,
Premier League from 1992/93), seasons 1974/75 to 2020/21.

| Column | Meaning |
|---|---|
| `season` | Season in English league form, e.g. `1981/82` |
| `startYear` | The calendar year the season started — the key the rules table uses |
| `matches` | Matches played that season |
| `homeWins`, `draws`, `awayWins` | Result counts. These three always sum to `matches` |
| `goals` | Total goals scored by both sides across the season |

Rates are deliberately **not** stored. They are computed from the counts, so
there is one source of truth and no rounded figure to drift.

### Source

Derived from **engsoccerdata**, compiled by James Curley —
https://github.com/jalapic/engsoccerdata (`data-raw/england.csv`).
Free for non-commercial use; the source should be cited. This game is a
personal, non-commercial project.

Retrieved 20 September 2026 (BST). The full dataset holds 208,028 matches across
the top four tiers from 1888; 50,570 of those are tier 1. This file is the
per-season aggregate of the tier-1 rows for the seasons above, and nothing else.

### How it was derived

For every tier-1 match in the season: the `result` column gives `H`, `D` or `A`,
and `totgoal` gives the match's total goals. The counts here are simple sums of
those, per season. No filtering, no exclusions.

### Positive control — why you can trust this file

`CALIBRATION_era-bands-1981-82_FINDINGS.md` cited an outside benchmark of
**2.65 goals per game across 11,266 Premier League matches, 1992–2021**, found
from a different source entirely.

Summing seasons 1992/93 to 2020/21 in this file gives **11,266 matches** and
**2.6555 goals per match**. Same match count, same figure, independent route.

⭐ If someone edits this file, that control is the first thing to re-run. A
change that breaks it means the file is wrong.
